# WeChat emoji assets

Source: [airinghost/wechat-emoji](https://github.com/airinghost/wechat-emoji),
commit `2896eb55348041f5c5a66e4eccfb4882ab9cda0c`.

The 109 numbered WebP files are copied without image changes from
`web.wechat.com/compressed-cwebp/lossless-z9/`; the original Chinese names
are recorded in `src/client/features/composer/wechatEmoji.ts`.
The upstream README attributes these images to Web WeChat (accessed 2022-01-08).

The upstream repository does not include an explicit license. These third-party
images are not covered by this project's source-code license.
