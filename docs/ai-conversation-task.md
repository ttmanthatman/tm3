# AI 自主对话任务卡

- 基线：a85ef29；现有依赖可用，图谱工具不可用。远端读取失败，基于本地版本实现。
- 目标：频道创建者邀请角色，设置自主对话预算并在频道内开始、暂停、继续、终止；管理员分级设置角色和四家模型服务。
- 所有者：当前会话执行并按验收条件复核；无委派和依赖任务。
- 允许范围：AI 设置、频道角色归属、多角色服务及其客户端、共享契约、对应测试和模块说明。
- 禁止范围：数据库结构、迁移、发布文件、Service Worker、部署、其他工作区改动。
- 复现：设置页宽表溢出；公开频道默认出现全部虚拟角色；多角色启动后缺少预算和取消控制。
- 不变量：仅创建者或站点管理员修改与控制；读状态仍需频道访问；只使用当前启用且被邀请的角色；串行生成；旧会话生成不可写入新会话；暂停/终止应取消生成并等待已开始的写入；重启不自动续费运行。
- 失败场景：越权、移除角色、重复启动、暂停后迟到响应、请求失败、预算到期、频道切换和组件销毁。
- 验收：条数精确封顶，累计发送给模型的上下文字符封顶，运行时间不含暂停；任一到限停止；配置持久化、运行态安全停止；手机和桌面无横向溢出。
- 检查：针对服务/路由/接入的 Node 测试；最终 verify:full；隔离频道/AI 设置 E2E 和响应式浏览器验收。
- 验证结果：24 项针对性服务/路由/接入测试通过；最终 verify:full 通过（226 个源测试文件、类型、lint、公开树检查和生产构建）；隔离 E2E 4/5 通过，数据恢复与站点重启成功。
