# 任务卡：真迹壹笔锋

## 基线
- Commit：3c80c9e；Node 22，依赖已安装；图谱工具不可用，采用定向源码定位。

## 目标
- 新增真迹壹：停顿后持续减速至抬笔，追随最新方向；急转固定尾尖，沿垂直于新轨迹的折线随距离翻折并留下扫过的墨迹；细长尾锋，无侧向扭动。

## 非目标
- 不改变旧算法的动力学、默认选择、按下中心、数据库、发布或部署。

## 所有者
- 当前执行者实现及按验收断言复核；无委派或跨会话交接。

## 依赖任务
- 无；保留工作区原有的未跟踪原生客户端契约工作。

## 允许修改文件
- 手写客户端功能及测试、共享手写契约及测试、账号偏好接口对新毛笔字段的严格校验及测试、相关浏览器测试和手写模块说明。

## 禁止修改文件
- 数据库、迁移、发布元数据、Service Worker、其他功能与原生客户端契约。

## 复现
- 旧算法仅旋转和横向弯曲；没有固定尾尖翻折、停顿转向倍率或第三个算法选项。

## 验收条件
- 停顿阈值默认 200ms，倍率默认 0.1，可输入并随账号保存、随笔画冻结。
- 减速保持到本笔结束，目标方向持续更新；方向差严格大于 135° 才翻折。
- 尾尖纸面坐标固定、折线与新方向垂直；停住不推进，展开后释放；扫过的边缘沉积墨迹。
- 实时、静态、部分回放一致；旧笔画兼容；三种算法可选择。

## 检查
- 定向：真迹壹几何、手写渲染、composable、共享契约测试。
- 完整：共享消息契约新增可选字段，执行一次最终 `npm run verify:full`。
- 浏览器：隔离手写和抄写 E2E，360/390/1280 视口及 WebKit；不需要迁移检查。

## 未验证项
- iOS 真机及真实压感笔硬件未实测；模拟触摸不能代表硬件表现。
- 手写与抄写 E2E 首轮 13/15 通过；旧消息重播单独复跑通过。触屏笔尖镜比画板上沿越界 2px 的断言在未修改基线也复现，保留为独立布局问题，不扩展本任务范围。

## 停止条件
- 同一故障两次修复失败；需要越界修改；发现无法解释的工作区重叠。

## 最终报告格式
- 修改文件、测试结果、剩余风险。
