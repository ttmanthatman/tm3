# 手机毛笔起笔与轮廓优化

- 基线：2.5.1（eec786b）；单执行者，无代码图谱工具，按符号定位。
- 目标：原地微晃后加速不留下过大的笔刷印章；保留短点、斜锋和旧笔迹外观。
- 范围：手写客户端动力学、轮廓和采样接线；可选毛笔版本的共享校验；相关测试、模块说明和 2.5.2 发布元数据。
- 不变量：旧笔画无版本标记时维持原算法；新标记严格校验并持久化；实时增量、静态和逐点回放保持一致；保留原始采样数据；不修改数据库、权限或消息幂等逻辑。
- 失败场景：微晃累计假位移、慢按产生大头、加速突然变细、丢失短点、转折产生齿边、抬手变粗、旧草稿被升级、回放不一致。
- 复现：手机触控按下，原地轻晃约 300 毫秒后快速拉出横线；分别使用两种算法、粗细 84、速度响应 50、滞后 100。
- 验收：限制无方向接触点；使用真实有效的平滑路径；约束轮廓粗细斜率；连续扫掠圆润截面；旧笔迹兼容；版本经服务端收发保留。
- 检查：针对性动力学、轮廓、composer、共享校验和服务测试；最终树一次 verify:full；隔离 tm3_e2e 手写与抄写浏览器回归；检查完整 diff 后只提交本任务路径。
- 未验证项：真机手指的触觉与主观书写感需发布后实测；模拟触控不能等同于真机。
